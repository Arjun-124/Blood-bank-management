
# Blood Bank Management System

## Description
A menu-driven application developed using C to manage blood donors and blood stock using file handling.

## Features
- Login System
- Add and View Donors
- Search Donors by Blood Group
- Check Blood Availability
- Request Blood
- Update and Delete Donors
- Generate Stock Reports

## Technologies Used
- C Programming
- File Handling
- GCC Compiler

## Files
- `main.c` - Main function and login
- `blood_bank.c` - Function definitions
- `blood_bank.h` - Function prototypes

## Compile and Run
```bash
gcc main.c blood_bank.c -o bloodbank
./bloodbank
```
